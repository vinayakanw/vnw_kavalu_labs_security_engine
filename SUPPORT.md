## Where to ask

| Situation | Channel |
|---|---|
| "How do I…?" / ideas / show-and-tell | [GitHub Discussions](https://github.com/vinayakanw/vnw_kavalu_security_engine/discussions) |
| Something is broken and you can reproduce it | [Open a bug report](https://github.com/vinayakanw/vnw_kavalu_security_engine/issues/new/choose) |
| You want a new feature or check | Open a feature request or new-check proposal |
| You found a **security vulnerability in this project** | **Do not post publicly.** See [SECURITY.md](SECURITY.md) |
| Business or private enquiries | Contact details at <https://www.nayaka100.in/> |

## What to include in a bug report

The bug template asks for these. Reports with them get answered fastest:

1. What you did, what you expected, and what happened
2. Engine version/commit, Python version, OS, and how you run it (local, Docker, Render)
3. The `scan_types` you used (never paste a URL you are not allowed to publish; use a placeholder)
4. The relevant log output or the finding JSON, **with secrets and private hostnames removed**

This is a volunteer-run project: there is no guaranteed response time or commercial support.
